# The Strategic Owl — V2

This is the clean, GitHub Pages-ready version of The Strategic Owl website.

## Page names

- `index.html` — Home
- `owl-feed.html` — Owl Feed
- `news-feed.html` — Owl Access News Feed
- `credibility-scores.html` — Credibility Scores
- `tru-rankings.html` — T.R.U. Rankings
- `voter-resources.html` — Voter Resources
- `media-influence-quiz.html` — Media Influence Quiz
- `fact-check-hub.html` — Fact Check Hub
- `constitution.html` — The Constitution
- `support.html` — Support & Connect

## Shared files

- `assets/css/site.css` controls the shared responsive appearance.
- `assets/js/site-shell.js` creates the shared navigation and footer.
- `assets/js/owl-access.js` controls the shared Owl Access icon, validation window, and sign out.
- Each page's original styles and behavior live in its matching file under `assets/css/pages` and `assets/js/pages`.

Upload the contents of this folder to the root of the `TSO-v2` repository. GitHub Pages should publish from the `main` branch and repository root.
